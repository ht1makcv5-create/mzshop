# Cloudinary — сховище фото (без картки, просто)

Storage у Firebase тепер вимагає банківську картку, тому фото зберігатимемо на **Cloudinary** — теж безкоштовно, картка не потрібна.

---

### Крок 1. Реєстрація

1. Відкрий **cloudinary.com**
2. Натисни **Sign up** (можна через Google-акаунт — швидше)
3. Заповни коротку анкету (тип використання можна обрати будь-який, наприклад "Other")

---

### Крок 2. Знайти "Cloud name"

1. Після входу ти потрапиш на **Dashboard** (головну сторінку)
2. Зверху побачиш напис **"Cloud name: ..."** — це і є твій `CLOUDINARY_CLOUD_NAME`, скопіюй його

---

### Крок 3. Створити "Upload preset" (дозвіл на завантаження без пароля)

1. Зверху праворуч натисни на іконку шестерні ⚙️ (Settings)
2. У меню зліва обери **Upload**
3. Прокрути вниз до розділу **Upload presets** → натисни **Add upload preset**
4. У полі **Signing Mode** обери **Unsigned** (це важливо — без цього завантаження не працюватиме)
5. Збережи (**Save**)
6. Тебе поверне до списку — там з'явиться назва нового preset (щось типу `ml_default` або згенерована назва) — скопіюй цю назву, це `CLOUDINARY_UPLOAD_PRESET`

---

### Крок 4. Вставити в наш файл

Відкрий **firebase-config.js**, знайди рядки:

```
export const CLOUDINARY_CLOUD_NAME = "ВАШ_CLOUD_NAME";
export const CLOUDINARY_UPLOAD_PRESET = "ВАШ_UPLOAD_PRESET";
```

Заміни `"ВАШ_CLOUD_NAME"` на те, що скопіював у Кроці 2, і `"ВАШ_UPLOAD_PRESET"` на те, що скопіював у Кроці 3. Збережи файл і залий на хостинг замість старого.

---

**Все.** Далі в адмінці на сайті фото завантажуватимуться саме сюди, а посилання на них зберігатиметься у Firestore — так, як і планувалось, тільки без картки.
